Rules

No icon fonts, no SVGs. Use plain Unicode so the UI inherits the user's system font rendering and avoids network / bundle overhead.

Hover-reveal. Row-level action glyphs (✎, ✕, ☆) default to visibility: hidden and appear on tr:hover. State-relevant icons (an active ★, an excluded row's ↻) stay visible.

Sizing. Row action glyphs are 13–14px colored #999 (or #aaa for storage), hover #333 (#444 for storage). Tree carets are 10px.
